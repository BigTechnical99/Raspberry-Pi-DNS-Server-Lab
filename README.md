# Raspberry-Pi-DNS-Server-Lab
Raspberry Pi DNS security Lab using AdGuard Home, Unbound, Linux, SSH, DNSSEC, and network-wide DNS filtering. 

## Overview

This project documents the deployment of a Raspberry Pi-based DNS security server using Raspberry Pi OS, AdGuard Home, and Unbound.

The goal of this project is to implement network-wide DNS filtering while gaining hands-on experience with Linux administration, DNS, DHCP, SSH, DNSSEC, network security, monitoring, and infrastructure troubleshooting.

## Project Goals

- Deploy a headless Raspberry Pi Linux server
- Configure secure remote administration using SSH
- Configure reliable network addressing for the DNS server
- Deploy AdGuard Home for network-wide DNS filtering
- Implement client-specific DNS filtering policies
- Configure family-friendly DNS protections and Safe Search
- Configure Unbound for recursive DNS resolution
- Implement DNSSEC validation
- Monitor and analyze DNS queries
- Practice Linux service administration
- Develop structured network troubleshooting procedures
- Document the deployment using Git and GitHub
