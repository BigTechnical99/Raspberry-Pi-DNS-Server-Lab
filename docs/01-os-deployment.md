# Phase 2 - Raspberry Pi OS Deployment

## Objective

Deploy Raspberry Pi OS Lite as a lightweight, headless Linux operating system for the Raspberry Pi DNS security server.

The system will be configured for remote administration over SSH and connected to the local network using Ethernet.

## Hardware Used

- Raspberry Pi
- MicroSD card
- MicroSD card reader
- Ethernet cable
- Raspberry Pi power supply
- Existing computer used for initial setup

## Software Used

- Raspberry Pi Imager
- Raspberry Pi OS Lite (64-bit)
- SSH

**Status:** In Progress
